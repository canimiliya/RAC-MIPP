# Local AI Paper Usage

- PDFs are stored under `.papers/` by category and paper ID.
- `.papers/` and all PDFs are local-only and are ignored by Git.
- Local AI should look up a paper by ID before opening its PDF.
- A filename's existence does not prove that its citation metadata is correct.
- Citation metadata must follow the verified entries in `docs/LITERATURE_CATALOG.md`.
- For S1 work, prioritize P01 and P03.
- For MAPPO work, use P04 and P06.
- For communication work, use P08, P09, and P13.
- For graph work, use P07 and P10.
- For risk work, use P11, P12, and P16.

This document does not authorize S1 reproduction, algorithm implementation,
training, or experiments.
