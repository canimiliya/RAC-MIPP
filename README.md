# RAC-MIPP

**Risk-Aware Communication-Constrained Multi-UAV Informative Path Planning**

RAC-MIPP is a research repository. [`PROJECT_PROGRESS.md`](PROJECT_PROGRESS.md)
is the project's sole master control document and defines the authorized scope,
stage gates, and evidence rules.

The upstream `ipp-marl` repository is retained only as a local ignored
dependency under `.deps/ipp-marl`; it is not tracked or publicly redistributed
from this repository.

The project is currently in stage **S0**. Training, long-running experiments,
algorithm implementation, and any later stage require explicit authorization
from the project controller.
